class toetactic.game.Game[source]¶

Represent a single CLI Tic Tac Toe game session.

Variables:

  • board (toetactic.board.Board) – Board being played on.

  • human (HumanPlayer) – The human player, always marked "X".

  • opponent (toetactic.player.Player) – The AI opponent, always marked "O".

run() → None[source]¶

Run the game loop until win or draw.

Calls setup() first, then alternates turns between the human and the opponent, redrawing the board after every move, until a player wins or the board fills up.

setup() → None[source]¶

Prompt for board size, player name, and opponent selection.

Populates board, human, and opponent from the collected input, replacing the defaults set in __init__().

class toetactic.player.Eleanor(name: str, mark: str)[source]¶

Bases: Player

Opponent that builds rows and columns, avoiding diagonals if possible.

choose_move(board: Board, opponent_mark: str) → tuple[int, int][source]¶

Choose a move by favouring row/column lines over diagonals.

Restricts itself to non-diagonal cells whenever any remain: among those, it takes an immediate win, then blocks an immediate opponent win, then advances whichever open row or column line it has already made the most progress on. Diagonal cells are only used once no non-diagonal cell is available.

Parameters:

  • board – Current board state.

  • opponent_mark – Mark used by the opposing player.

Returns:

Zero-based (row, col) coordinates of the chosen move.
